Design Choices (4–5 Lines)


A blue and teal color palette gives the website a professional and modern appearance.

Arial typography provides clear and readable text across all pages.

CSS variables maintain consistent colors, spacing and reusable design values.

Navigation, buttons, forms and tables are styled consistently for a better user experience.

Responsive CSS and hover effects improve usability on mobile devices and desktop screens


 DevTools Debugging


Open index.html in Google Chrome.

Right-click any element and select Inspect.

In the Elements → Styles panel, inspect CSS rules and test changing colors or spacing.

Check the Console for errors and confirm all three pages load the external style.css.

Save any changes in your code editor and refresh the page to verify the result.
